# The Crumb Atelier — WebKadai Demo Bakery Website

A premium demo website for a fictional artisan bakery & patisserie ("The Crumb Atelier", Nungambakkam, Chennai), built by **WebKadai** to show bakery clients what their business website could look like.

## What's inside
- Single self-contained `index.html` (no build step, no server)
- 3D mouse-tilt hero, scroll animations, animated counters
- "Today's bake schedule" section, 4-category menu (24 items) and a **pre-order tray** — customers add bakes/cakes, pick a pickup date, and send the pre-order to WhatsApp in one tap
- Real opening-hours status, story, gallery, reviews

## Deploy on Vercel
Import this repo at [vercel.com/new](https://vercel.com/new) → Deploy. No settings to change — it's a static site (`index.html` at root, images in `assets/`).
